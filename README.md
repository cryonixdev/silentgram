# Silent Gram

Личный клиент Telegram для iPhone: режим призрака, сохранение удалённых сообщений и истории правок, настраиваемое оформление.
Работает на TDLib (официальная библиотека Telegram), интерфейс на SwiftUI, iOS 16+.

## Что умеет
- 👻 **Режим призрака** (каждую функцию можно включить отдельно): не показывать «в сети», не отправлять «прочитано», не показывать «печатает…», уходить в офлайн сразу после отправки сообщения. Кнопка с глазом в списке чатов включает и выключает его.
- Чат можно отметить прочитанным вручную: свайп вправо или долгое нажатие.
- 🗑 **Удалённые сообщения** остаются в чате и помечаются красным.
- ✏️ **История правок**: долгое нажатие на сообщение → «История правок».
- 🎨 **Оформление**: 6 готовых тем, свои цвета пузырей и акцента, фон (градиент, цвет или своё фото), скругление и размер текста.

## Как собрать и установить

1. **Ключи API.** Зайди на https://my.telegram.org → API development tools, создай приложение и скопируй `api_id` и `api_hash`.
2. **Репозиторий.** Создай репозиторий на GitHub и залей туда все файлы из архива, включая скрытую папку `.github`.
   Публичный репозиторий собирается бесплатно без лимитов. У приватного есть ограничение по минутам сборки на macOS.
3. **Секреты.** Settings → Secrets and variables → Actions → New repository secret:
   - `TG_API_ID` — число
   - `TG_API_HASH` — строка
   Ключи хранятся только в секретах и в репозиторий не попадают.
4. **Сборка.** Actions → **Build IPA** → Run workflow. Сборка идёт около 10–20 минут. Готовый архив `SilentGram-ipa` скачай и распакуй, внутри будет `SilentGram.ipa`.
5. **Установка.** Перекинь IPA на iPhone и открой в SideStore: My Apps → «+».

Если сборка упала, скачай артефакт `build-log` или скопируй ошибку из лога.

## Ограничения
- Push-уведомлений нет: для них нужен платный аккаунт разработчика Apple. Новые сообщения приходят, пока приложение открыто.
- Пока поддерживаются текст и фото. Остальные типы сообщений показываются подписью: «🎤 Голосовое», «🎬 Видео» и т. п.
- Режим призрака нарушает правила Telegram API. Риск небольшой, но он есть.
